# Aircraft-Performance-Flight-Test Analysis
Python tools to analze flight data and generate performance reports similar to Denel Flight test operations.

## What it does
- calculates takeoff, climb, and G-loading performance
- Generates safety envelope plots
- produces formal flight test reports
- Interactive dashboard coming

- ## Skills
  Python, Pandas, NumPy, Data Analysis, Flight Test

  ## How to run
  'pip install pandas numpy'
  'python analysis/performance.py'
